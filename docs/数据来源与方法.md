### 为什么投档线用第三方整理的数据

本次实测了官方渠道的可获取性：

- `www.hbea.edu.cn`（湖北省教育考试院）可访问，但站内文章页全部 301 跳转到 `www.hbksw.com`；
- `www.hbksw.com`（湖北招生考试网）首页可访问，**文章页与数据接口持续返回 502**，
  其院校数据库前端调用的是 `/api/college/...`（可见于 `/js/college.js`），该接口同样不可用；
- `jyt.hubei.gov.cn`（湖北省教育厅）可访问，投档线以 **PDF 附件**形式发布，一分一段以**图片**形式发布；
- `gaokao.chsi.com.cn`（阳光高考）返回 412 拦截；`api.gaokao.cn` 不可达；
  掌上高考旧静态接口 `static-data.gaokao.cn/...` 已失效（返回 NoSuchKey）。

因此：投档线采用「官方 PDF → 开源项目结构化」的成熟数据（该仓库同时保存了原始 PDF 与来源说明），
并用官方批次线做交叉校验；一分一段目前只能拿到 2024 年的数字化版本。

> 注：上述志愿数量取自**征集志愿公告**原文；常规批次的表述以当年招生实施办法为准，
> 工具中的参数（`data/meta.js` → `policy.batches`）已附带出处链接，可随时修改。

### 1. 投档线（`data/admissions_*.js`）

每条记录是**一个院校专业组**（不是学校、不是专业）：

```
[院校代码(国标,5位), 院校名称, 院校所在省, 专业组号, 选科要求, 投档最低分, 院校标签, 备注]
```

- **专业组号**：从官方的「03 化学」里拆出来的 `03`；`选科要求` 为 `化学`、`不限`、`化学+生物` 等。
  `+` 按「均须选考」处理（与官方计划的写法一致）。
- **投档最低分**：`null` 表示当年该专业组**没有出档考生（缺额）**，工具默认不展示，可勾选后查看。
- **院校标签**：`985` / `211` / `双一流` / `民办`；空表示普通本科。
- **备注**：`中外合作办学`、`国家专项计划`、`民族班` 等；工具默认排除后两类与中外合作。
- 同一所院校的**本部 / 深圳 / 威海校区 / 医学院**共用国标代码，但院校名称不同，工具按
  「代码 + 名称 + 专业组 + 备注」区分，不会混成一条。

### 2. 一分一段表（`data/segments_*.js`）

```
[分数, 本分人数, 累计人数]
```

累计人数 = 该分数及以上的考生总数，也就是该分数对应的**位次上限**。表按分数从高到低排列。

## 三、算法说明

### 1. 线差法（默认）

```
我的等效分 = 我的分数 − 我的划线 + 参考年批次线
分差      = 我的等效分 − 该院校专业组在该年的投档最低分
```

- 没填「我的划线」时，用参考年的官方批次线替代（等价于「假设今年难度和参考年一样」）。
- 分差 ≥ 冲线阈值 → **冲**；≥ 稳住阈值 → **稳**；≥ 保底阈值 → **保**；再往上 30 分记为 **超保**；
  低于冲线阈值 → **风险**（默认隐藏，可勾选查看）。
- 阈值默认 −10 / 0 / 12 分，可在界面左侧拖动调整。

### 2. 位次法（需要一分一段表）

```
该院校专业组的位次 = 一分一段表(投档最低分).累计人数
位次比            = 我的位次 / 该专业组位次
```

- 位次比 > 1.15 → **风险**；1.0 ~ 1.15 → **冲**；0.85 ~ 1.0 → **稳**；0.6 ~ 0.85 → **保**；< 0.6 → **超保**。
- 一分一段表里没有正好等于投档分的分数时，用相邻两档做**线性插值**。

### 3. 选科硬过滤

按官方专业组的选科要求做集合判断：

| 要求写法 | 判定 |
| --- | --- |
| `不限` | 直接通过 |
| `化学` | 再选科目里必须含化学 |
| `化学+生物` | 化学和生物都必须选 |
| `化学或生物` | 含其中一个即可 |

首选科目（物理 / 历史）由数据文件本身区分，不存在混淆。

### 4. 模拟投档

按湖北平行志愿规则实现：**分数（位次）优先、遵循志愿、一轮投档**。
从第 1 个志愿开始逐个检索，遇到第一个够线的志愿即投出，其后的志愿不再检索；
全部不够线则输出「滑档」。模拟仅基于投档分/位次，不含专业级差、体检、单科要求。

### 4. 已知边界情况

- 专科批存在 **150~151 分** 的投档分（低于专科线 200），通常是征集志愿降分或缺额补录；
  工具会在表格里打「低线」标记，提醒核对原始投档线。
- 本科批也存在少量低于本科线较多的记录，多为**预科班 / 民族班 / 专项计划**；
  工具默认已排除这些特殊类型。
- 部分院校专业组只在某一年出现（组号每年会调整），趋势列会显示「—」，这是正常现象。

## 五、局限与风险

1. **没有组内专业清单**：无法判断某个专业组里具体有哪些专业，也无法评估「被调剂到不喜欢专业」的风险。
2. **2025/2026 无法用位次法**：一分一段表缺失（官方以图片发布），只能线差法。
3. **院校专业组代号每年变化**：志愿表里的代号栏必须用当年《招生计划》填写，工具只做到识别层面。
4. **不预测**：工具刻意不给出「录取概率」，因为投档线波动、计划增减、报考热度都无法从历史数据外推成精确数字。
5. **合规**：数据仅供个人分析使用，不得商用；官方数据版权归发布单位所有。
