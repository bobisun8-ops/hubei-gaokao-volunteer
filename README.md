# 湖北（武汉）高考志愿工作台

面向湖北（尤其是武汉）考生的高考志愿填报预案工具，按湖北新高考「院校专业组」口径实现。
**双击 `打开志愿工作台.bat` 就能用**，不需要装 Python、不需要联网、不依赖任何服务器。

> 想直接分享给别人：发 `湖北高考志愿工作台-单文件版.html` 这一个文件就行，
> 对方双击用浏览器打开即可（数据全部内置，1.6 MB）。

---

## 一、它能干什么

1. **定位**：把考生的模考分数（或全省位次）换算到参考年份口径，和真实的院校专业组投档线对齐。
2. **筛选**：按选科要求硬过滤（再选科目不对直接排除），再按院校层次、所在省份、是否中外合作 / 专项计划筛选。
3. **分档**：把匹配结果分成「冲 / 稳 / 保 / 超保」，每条都能看到 **2024、2025、2026 三年的投档分**走势。
4. **出志愿表**：一键加入志愿表，自动做结构体检（冲稳保比例、保底够不够、不服从调剂条数），
   可导出 CSV（Excel 直接打开）或打印成纸质表照着填系统。
5. **模拟投档**：按湖北「分数（位次）优先、遵循志愿、一轮投档」规则推演一遍，看会投到第几个志愿、会不会滑档。

---

## 二、三步用法

| 步骤 | 做什么 |
| --- | --- |
| 1 | 左侧「考生情况」：选首选科目（物理 / 历史）、勾 2 门再选科目、选报考层次 |
| 2 | 左侧「成绩定位」：填**本次考试总分**；如果学校给了模拟划线就填上；有全省位次一定填（更准） |
| 3 | 点「开始匹配」→ 看结果 → 「加入志愿表」→ 切到「我的志愿表」导出或打印 |

**高三上学期怎么用**：用最近一次大考分数 + 学校给的模拟划线（例如「模拟本科线 430」），
先看自己能摸到哪个层次，把目标院校专业组放进志愿表，之后每次大考更新一次分数，观察名单变化。
**出分后怎么用**：填真实分数 + 当年批次线（或直接填位次），一小时出正式预案。

## 三、两种定位方法（重要）

| 方法 | 怎么算 | 什么时候能用 |
| --- | --- | --- |
| **线差法**（默认） | 我的等效分 = 我的分数 − 我的划线 + 参考年批次线，再和投档最低分比分差 | 任何时候都能用，只要填了分数 |
| **位次法** | 把我的全省位次和院校专业组投档分换算出的位次直接比较 | 需要**该年份的一分一段表** |

现在只有 **2024 年**有一分一段表，所以参考 2024 年时自动用位次法，参考 2025/2026 年时用线差法。
把官方 2025/2026 一分一段表录进来就能解锁对应年份的位次法（见第七节）。

档位默认阈值（可在左侧滑块调整）：

- **冲**：分差 −10 ~ 0 分（投档线比自己高一点点，值得试）
- **稳**：分差 0 ~ 12 分
- **保**：分差 12 ~ 42 分
- **超保**：分差 42 分以上（分数浪费较多，一般不用排进志愿表）

## 四、数据是什么、从哪来

内置 **湖北 2024 / 2025 / 2026 三年、物理类 + 历史类、本科 + 高职高专，共 20,450 条**
院校专业组投档最低分记录，每条都带着院校代码、院校名称、所在省份、专业组号、选科要求、院校层次标签。

| 数据 | 年份 | 来源 |
| --- | --- | --- |
| 投档线（院校专业组） | 2024 / 2025 / 2026 | 湖北省招办公布的投档最低分 PDF，经开源项目 [secnotes/gaokao](https://github.com/secnotes/gaokao)（MIT）结构化整理 |
| 一分一段表 | 2024 | 湖北省教育考试院公布，经 [FlySky-z/gaokao-analysis](https://github.com/FlySky-z/gaokao-analysis) 数字化 |
| 批次线（录取控制分数线） | 2024 / 2025 / 2026 | 湖北省教育厅《录取控制分数线》通知；[中国教育在线历年分数线汇总](https://www.eol.cn/e_html/gk/fsx/index.shtml) 核对 |

每个数据文件都记录了下载地址、字节数和 SHA-256 校验值，在页面右上角「数据来源」里可以逐条查看。
构建时的对账结果见 `docs/数据构建与对账报告.md`（记录数逐一对账、投档分区间检查、一分一段累计人数单调性检查）。

### 已知数据缺口（务必了解）

1. **一分一段表只有 2024 年**：湖北官方把 2025/2026 一分一段做成图片发布，程序读不了，
   需要人工录入（工具提供了录入脚本）。在录入之前，这两年只能用线差法。
2. **没有「组内专业」清单**：原始投档线只到「院校专业组」粒度，具体招哪些专业、专业代码是多少，
   要对照当年官方《招生计划》。志愿表里 6 个专业栏留空给考生填。
3. **院校代号不是当年的**：湖北志愿系统用的是当年《招生计划》里的院校专业组代号，每年都变。
   本工具展示的是国标院校代码（5 位），只用于识别；填系统时请以官方计划的代号为准。

## 五、湖北志愿填报的口径（工具已按此实现）

- 3+1+2 模式：首选物理 / 历史分开排队，**物理类和历史类的分数不能互相比较**（工具里分开处理）。
- 志愿单位是**院校专业组**，不是学校；再选科目必须满足专业组的选科要求（工具做硬过滤）。
- **本科普通批 45 个院校专业组志愿**、**高职高专普通批 30 个**（湖北省教育厅招生办公室 2026 年公告原文，
  链接见 `docs/数据来源与方法.md`）；每个志愿内 6 个专业 + 是否服从调剂。
- 平行志愿投档规则：**分数（位次）优先、遵循志愿、一轮投档**。

> 以上数量与规则来自官方公开的招生公告，**每年请以湖北省教育考试院当年文件为准**；
> 相关参数写在 `data/meta.js` 的 `policy` 字段里（含公告出处链接），改动后刷新页面即可生效。
> 工具会按层次自动取上限：本科 45 个、高职高专 30 个。

## 六、它不会做什么（避免误用）

- **不预测分数线**，也不给「录取概率 87%」这类看着精确、实则没有依据的数字。
- **不编造数据**：任何一条推荐都能在「数据体检」里追溯到来源文件；没有数据的就显示「—」。
- 不考虑专业级差、体检限制、单科成绩要求、外语语种、口试等细则 —— 这些必须查高校招生章程
  （官方征集志愿公告本身就明确提醒：「填报志愿看章程」）。
- 不替代老师、招生办的意见。**这是预案工具，不是决策替代品。**

## 七、每年怎么更新数据

需要 Python 3.10+（只用标准库，不用 pip 安装任何包）：

```bash
cd gaokao-hubei
python tools/fetch_data.py      # 下载最新投档线 + 一分一段到 data_raw/
python tools/build_data.py      # 规范化 + 对账校验 + 重新生成 data/*.js
```

每年 6 月底新数据出来后重跑这两条命令即可（如果新的年份没有一分一段，工具会自动只用线差法）。

### 补录一分一段表（解锁位次法）

```bash
# 1) 生成空白模板
python tools/import_segment.py --template --year 2025 --category 物理类

# 2) 照着官方一分一段表，把「累计人数」列填上（本段人数可留空）

# 3) 导入
python tools/import_segment.py --year 2025 --category 物理类 --input 一分一段模板_2025_物理类.csv
python tools/build_data.py
```

导入时脚本会自动校验：累计人数必须单调不减、累计人数合计要和本段人数合计对得上，
对不上会直接告诉你「可能漏抄了中间分数段」。

## 八、文件结构

```
gaokao-hubei/
├─ 打开志愿工作台.bat          # 双击启动（就是打开 index.html）
├─ index.html                 # 界面
├─ assets/
│   ├─ gk.js                  # 数据装载器
│   ├─ app.js                 # 匹配、筛选、分档、模拟投档、导出的全部逻辑
│   └─ style.css              # 样式（含打印样式）
├─ data/                      # 前端加载的数据（由构建脚本生成）
│   ├─ meta.js                # 政策参数、批次线、来源清单、数据缺口说明
│   ├─ index.js               # 加载清单
│   ├─ admissions_*.js        # 12 个投档线文件（3 年 × 2 科类 × 本科/专科）
│   └─ segments_*.js          # 一分一段表
├─ data_raw/                  # 原始下载文件 + sources.json（含 SHA-256）
├─ docs/
│   ├─ 数据构建与对账报告.md     # 每次构建自动生成
│   └─ 数据来源与方法.md        # 数据口径、算法说明、验证记录
└─ tools/
    ├─ fetch_data.py          # 抓取数据
    ├─ build_data.py          # 构建 + 对账
    └─ import_segment.py      # 一分一段表导入
```
